# Stadium Escape

A soccer-themed scrolling platformer created for CS-UY 3113 Project 4. Cross three increasingly difficult levels, avoid defenders, and reach each finish flag before losing all three lives.

## Controls

- **Enter:** Start the game or return to the menu
- **A / D:** Move left or right
- **W:** Jump
- **1 / 2 / 3:** Switch levels
- **Q:** Quit

## Features

- Menu, Win, and Lose scenes
- Three scrolling levels
- Shared lives system
- Wanderer, follower, and jumper AI
- Animated player and defenders
- Background music and sound effects

## Build and Run

```sh
make
make run
```
